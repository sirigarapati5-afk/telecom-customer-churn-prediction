# Telecom Customer Churn Prediction & LTV Engine

## Project Overview

This project predicts customer churn using Machine Learning models and estimates Customer Lifetime Value (LTV) for telecom customers.

## Technologies Used

* Python
* Pandas
* Scikit-Learn
* XGBoost
* SHAP
* Streamlit
* FastAPI

## Features

* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Logistic Regression
* Random Forest
* XGBoost
* Model evaluation metrics
* SHAP explainability
* Customer LTV calculation
* Streamlit dashboard
* FastAPI integration

## Models Used

* Logistic Regression
* Random Forest Classifier
* XGBoost Classifier

## Deployment

* Streamlit for dashboard visualization
* FastAPI for API endpoints
* ngrok for temporary public deployment

## Future Improvements

* PostgreSQL integration
* Docker deployment
* Batch prediction support
* Cloud deployment
